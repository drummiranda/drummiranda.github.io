# Marlon — Portfolio

Portfólio one-page em HTML/CSS/JS, pensado para publicação no GitHub Pages.

## Estrutura

- `index.html` — conteúdo e estrutura do site
- `style.css` — layout, tipografia, responsividade e animações
- `script.js` — filtros, modal de projetos e scroll reveal
- `images/` — coloque aqui as imagens reais dos seus projetos

## Antes de publicar

No `index.html`, substitua:

- `seuemail@exemplo.com`
- links de Instagram, LinkedIn e Behance
- títulos, descrições e categorias dos projetos

Para transformar os blocos gráficos em trabalhos reais, substitua as classes `art-01` etc. por imagens, por exemplo:

```html
<button class="project-image" style="background-image:url('images/projeto-01.jpg')">
```

## Categorias

A estrutura atual contempla:

- Campaigns — KV e campanhas
- Branding — identidade e manual de marca
- Social — posts, reels e stories
- Motion — YouTube, vídeo e motion
- Print — flyers, anúncios e editorial
- Digital — pode ser adicionado aos filtros conforme necessário

## GitHub Pages

1. Crie um repositório chamado `SEUUSUARIO.github.io`.
2. Envie os arquivos deste projeto para a raiz do repositório.
3. No GitHub, abra `Settings > Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha `main` e `/ (root)`.
6. Salve.

O site ficará em `https://SEUUSUARIO.github.io`.
